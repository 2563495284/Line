# 游戏重启系统说明

## 问题背景

之前使用 `SceneManager.LoadScene()` 重新加载场景来重启游戏会导致各种 `MissingReferenceException` 错误，因为：

1. 场景重载会销毁所有 GameObject
2. 但某些系统可能仍持有对已销毁对象的引用
3. 协程和事件订阅在场景切换时可能出现时序问题

## 新的解决方案

### 核心思路
**不重新加载场景，而是重置所有游戏系统的状态**

### 实现架构

#### 1. GameProgressSystem.RestartGame()
- 停止所有协程
- 重置游戏进度状态
- 调用各个系统的 `ResetSystem()` 方法
- 重新初始化游戏

#### 2. 各系统的 ResetSystem() 方法

**MultiStockSystem.ResetSystem()**
- 重置玩家资金到初始值 (10000)
- 重置所有股票价格到初始价格
- 清空玩家持股
- 重置价格历史记录
- 更新K线显示

**PlayerAttributeSystem.ResetSystem()**
- 重置所有属性值为0
- 清空玩家手牌、牌堆、弃牌堆
- 销毁所有卡牌视图GameObject
- 更新UI显示

**NPCSystem.ResetSystem()**
- 清空所有NPC的手牌和牌堆
- 重置NPC状态

**ManaSystem.ResetSystem()**
- 重置当前能量到基础值
- 清空保存的能量
- 更新能量UI

#### 3. MatchSetupSystem 改进
- 改为 Singleton 模式
- 提供 `InitializeGame()` 公共方法
- 提供获取原始数据的方法

### 优势

1. **无引用问题**：所有对象都保持存在，只是重置状态
2. **性能更好**：不需要重新加载和实例化场景
3. **更可控**：可以精确控制哪些状态需要重置
4. **扩展性好**：新增系统只需实现 `ResetSystem()` 方法

### 使用方法

在 Unity 编辑器中：
1. 确保场景中有 `GameProgressSystem` 组件
2. 确保 `MatchSetupSystem` 使用了新的 Singleton 版本
3. 点击"重启人生"按钮即可无缝重启游戏

### 注意事项

- 所有新增的游戏系统都应该实现 `ResetSystem()` 方法
- 确保重置时清理所有动态创建的GameObject
- UI组件的引用检查仍然保留，作为额外的安全措施

## 文件修改列表

- `GameProgressSystem.cs` - 新的重启逻辑
- `MultiStockSystem.cs` - 添加 ResetSystem()
- `PlayerAttributeSystem.cs` - 添加 ResetSystem()
- `NPCSystem.cs` - 添加 ResetSystem()
- `ManaSystem.cs` - 添加 ResetSystem()
- `MatchSetupSystem.cs` - 改为 Singleton，提供初始化方法
