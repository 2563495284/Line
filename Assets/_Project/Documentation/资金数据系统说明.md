# 资金数据系统说明

## 概述

创建了一个新的 `FinancialData` ScriptableObject 类来管理游戏中的资金配置，类似于 `PlayerData` 的设计模式。

## 文件结构

### 新增文件
- `Assets/_Project/Scripts/Data/FinancialData.cs` - 资金配置数据类
- `Assets/_Project/ScriptableObjects/Financial/Default Financial Data.asset` - 默认资金配置资产

### 修改文件
- `Assets/_Project/Scripts/Systems/MultiStockSystem.cs` - 使用 FinancialData 进行初始化

## FinancialData 类功能

### 配置字段
```csharp
[Header("初始资金配置")]
[SerializeField] private float initialMoney = 200000f;

[Header("资金限制")]
[SerializeField] private float minMoney = 0f;
[SerializeField] private float maxMoney = float.MaxValue;

[Header("游戏目标")]
[SerializeField] private float targetAssets = 3000000f;
[SerializeField] private int maxRounds = 100;

[Header("显示格式")]
[SerializeField] private string moneyFormat = "N0";
[SerializeField] private string assetFormat = "N0";
```

### 公共方法

#### 访问器属性
- `InitialMoney` - 获取初始资金
- `MinMoney` - 获取最小资金限制
- `MaxMoney` - 获取最大资金限制
- `TargetAssets` - 获取目标资产
- `MaxRounds` - 获取最大回合数
- `MoneyFormat` - 获取金钱显示格式
- `AssetFormat` - 获取资产显示格式

#### 工具方法
- `ClampMoney(float amount)` - 将资金限制在有效范围内
- `FormatMoney(float amount)` - 格式化金钱显示
- `FormatAssets(float amount)` - 格式化资产显示
- `HasReachedTarget(float currentAssets)` - 检查是否达到目标资产
- `GetAssetProgress(float currentAssets)` - 计算资产达成进度 (0-1)

## MultiStockSystem 改进

### 初始化改进
```csharp
protected override void Awake()
{
    base.Awake();
    InitializeFinancialSystem();
}

private void InitializeFinancialSystem()
{
    if (financialData != null)
    {
        currentMoney = financialData.InitialMoney;
    }
    else
    {
        Debug.LogWarning("FinancialData 未设置，使用默认值 200000");
        currentMoney = 200000f;
    }
}
```

### 新增方法
- `GetFinancialData()` - 获取资金配置数据
- `SetCurrentMoney(float amount)` - 设置当前金币（使用配置的限制）
- `HasEnoughMoney(float requiredAmount)` - 检查是否有足够的资金
- `FormatMoney(float amount)` - 格式化金钱显示
- `FormatCurrentMoney()` - 格式化当前金钱显示

### 重置系统改进
```csharp
public void ResetSystem()
{
    // 重置玩家资金到初始值
    InitializeFinancialSystem();
    // ... 其他重置逻辑
}
```

## 使用方式

### 在 Unity Editor 中
1. 在 `MultiStockSystem` 组件中设置 `Financial Data` 字段
2. 可以使用提供的 `Default Financial Data` 资产，或创建自定义配置

### 在代码中
```csharp
// 获取资金配置
FinancialData config = MultiStockSystem.Instance.GetFinancialData();

// 检查是否达到目标
bool hasWon = config.HasReachedTarget(currentAssets);

// 格式化显示
string formattedMoney = MultiStockSystem.Instance.FormatCurrentMoney();

// 获取进度
float progress = config.GetAssetProgress(currentAssets);
```

## 优势

1. **配置分离**：资金配置与系统逻辑分离，便于调整
2. **可重用性**：可以创建多个不同的资金配置用于不同难度
3. **类型安全**：通过 ScriptableObject 提供类型安全的配置
4. **Inspector 友好**：在 Unity Editor 中直观地配置参数
5. **一致性**：与现有的 `PlayerData` 设计模式保持一致
6. **扩展性**：易于添加新的资金相关配置

## 创建新的资金配置

1. 在 Project 窗口中右键
2. 选择 `Create > Data > Financial`
3. 配置所需的参数
4. 在 `MultiStockSystem` 中引用新的配置

这种设计使得资金系统更加模块化和可配置，便于游戏平衡调整和不同模式的实现。
