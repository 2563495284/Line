# 新闻历史记录系统使用说明

## 功能概述

新闻历史记录系统是一个新增的功能模块，它将现有的新闻系统扩展为支持历史记录浏览。系统位于左下角，支持滑动浏览历史记录，并且新闻会在三条合并后才消失，而不是通过时间消失。

## 核心特性

### 1. 位置和布局
- **位置**：左下角
- **默认状态**：收起状态（只显示标题栏）
- **展开状态**：可滑动浏览完整历史记录
- **最新消息**：显示在最下面

### 2. 新闻合并机制
- **合并阈值**：3条新闻
- **合并逻辑**：当累积3条新闻后，这些新闻会被标记为"已合并"并消失
- **非时间消失**：新闻不会因为时间而自动消失

### 3. 滑动浏览
- **垂直滚动**：支持上下滑动浏览历史记录
- **自动滚动**：新消息出现时自动滚动到底部
- **平滑动画**：支持淡入淡出和展开/收起动画

## 系统架构

### 1. NewsHistorySystem
- **功能**：管理新闻历史记录和合并逻辑
- **特性**：单例模式，自动管理新闻生命周期
- **配置**：可调整最大历史记录数量和合并阈值

### 2. NewsHistoryUI
- **功能**：主要的UI组件，管理显示和交互
- **特性**：支持展开/收起，集成ScrollRect
- **动画**：平滑的尺寸变化和内容更新

### 3. NewsHistoryItemUI
- **功能**：单条新闻的显示组件
- **特性**：显示标题、内容、时间和类型
- **样式**：根据新闻类型自动设置颜色

## 使用方法

### 1. 在Unity中设置

#### 创建UI预制体
1. 在Canvas下创建一个新的GameObject，命名为"NewsHistoryUI"
2. 添加以下组件：
   - `NewsHistoryUI` 脚本
   - `RectTransform`（自动添加）
   - `Image` 作为背景

#### 设置正确的UI层级结构
为了实现"按钮固定在顶部，历史记录上下移动"的效果，必须按照以下结构设置：

```
NewsHistoryUI (根对象)
├── Header (按钮栏，固定在顶部)
│   ├── ExpandButton (展开/收起按钮)
│   └── ClearButton (清除按钮)
└── ContentArea (内容区域，会上下移动)
    ├── Viewport (带Mask组件)
    │   └── Content (ScrollRect的content)
    └── ScrollRect组件
```

**重要**: 请参考 `新闻历史记录UI层级结构说明.md` 文档获取详细的设置步骤。

#### 设置按钮
1. 添加展开/收起按钮
2. 添加清除历史按钮

#### 设置新闻项预制体
1. 创建NewsHistoryItemUI预制体
2. 包含以下UI元素：
   - 标题文本 (titleText)
   - 内容文本 (contentText)
   - 时间文本 (timeText)
   - 背景图片 (backgroundImage)
   - 类型图标 (typeIcon，可选)

### 2. 配置参数

#### NewsHistorySystem配置
- `maxHistoryCount`: 最大历史记录数量（默认50）
- `mergeThreshold`: 合并阈值（默认3）
- `historyUI`: UI组件引用

#### NewsHistoryUI配置
- `scrollRect`: ScrollRect组件引用
- `contentParent`: 内容父对象引用
- `itemPrefab`: 新闻项预制体引用
- `maxVisibleItems`: 最大可见项目数（默认8）
- `itemHeight`: 项目高度（默认200）
- `itemSpacing`: 项目间距（默认5）
- `startExpanded`: 是否默认展开（默认false）

### 3. 代码集成

#### 自动集成
系统会自动与现有的NewsSystem集成，无需额外代码修改。每次调用`BroadcastNews`时，新闻会自动添加到历史记录。

#### 手动控制
```csharp
// 手动刷新显示
NewsHistoryUI.Instance.ManualRefresh();

// 设置展开状态
NewsHistoryUI.Instance.SetExpanded(true);

// 获取当前状态
bool isExpanded = NewsHistoryUI.Instance.IsExpanded();

// 手动触发合并（测试用）
NewsHistorySystem.Instance.ForceMerge();

// 清除历史记录
NewsHistorySystem.Instance.ClearAllHistory();
```

## 事件系统

### 1. OnHistoryUpdated
- **触发时机**：历史记录更新时
- **参数**：当前可见的历史记录列表
- **用途**：通知UI更新显示

### 2. OnMergeGroupCompleted
- **触发时机**：新闻合并组完成时
- **参数**：无
- **用途**：可以添加合并完成的特效

## 样式定制

### 1. 颜色配置
每种新闻类型都有对应的颜色：
- `Info`: 蓝色
- `CardPlay`: 紫色
- `Trade`: 黄色
- `Positive`: 绿色
- `Negative`: 红色
- `Prediction`: 绿色
- `MarketEvent`: 紫罗兰色

### 2. 尺寸配置
- **收起状态**：350x30
- **展开状态**：350x470
- **项目高度**：200
- **项目间距**：5

## 性能优化

### 1. 对象池
- 新闻项UI使用对象池管理
- 自动清理已合并的新闻
- 限制最大历史记录数量

### 2. 渲染优化
- 只渲染可见的新闻项
- 使用CanvasGroup控制透明度
- 平滑的动画过渡

## 故障排除

### 1. 常见问题

#### UI不显示
- 检查NewsHistoryUI是否正确设置
- 确认ScrollRect和Content引用
- 检查Canvas设置

#### 新闻不添加到历史记录
- 确认NewsHistorySystem实例存在
- 检查NewsSystem的集成代码
- 查看Console日志

#### 滑动不工作
- 检查ScrollRect组件设置
- 确认Content尺寸正确
- 检查ScrollRect的enabled状态

### 2. 调试信息
系统提供丰富的调试信息：
```csharp
// 获取系统状态
string status = NewsHistorySystem.Instance.GetStatusInfo();
Debug.Log(status);

// 获取新闻项调试信息
string debugInfo = itemUI.GetDebugInfo();
Debug.Log(debugInfo);
```

## 扩展功能

### 1. 搜索功能
可以添加搜索框，支持按关键词搜索历史新闻。

### 2. 分类筛选
可以添加分类按钮，按新闻类型筛选显示。

### 3. 导出功能
可以添加导出按钮，将历史记录导出为文件。

### 4. 统计信息
可以显示新闻统计信息，如总数量、各类型分布等。

## 注意事项

1. **性能考虑**：大量历史记录可能影响性能，建议适当限制最大数量
2. **内存管理**：定期清理已合并的新闻，避免内存泄漏
3. **UI层级**：确保新闻历史记录UI在合适的层级显示
4. **多语言支持**：标题和按钮文本支持本地化配置
