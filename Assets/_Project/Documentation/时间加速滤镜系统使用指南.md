# URP时间加速滤镜系统使用指南

## 功能概述

时间加速滤镜系统为游戏提供视觉特效，表现时间快速流逝的感觉。该系统使用URP (Universal Render Pipeline) 的RenderFeature架构，与天堂制造功能完美集成。

## 核心文件

### 1. Shader文件
- **路径**: `Assets/_Project/Art/Materials/TimeAccelerationFilter.shader`
- **功能**: URP兼容的后处理滤镜Shader
- **特效**: 径向模糊、色彩偏移、亮度调制、扭曲效果

### 2. 材质文件
- **路径**: `Assets/_Project/Art/Materials/TimeAccelerationFilter.mat`
- **功能**: 滤镜Shader的材质实例
- **配置**: 预设了合适的默认参数值

### 3. URP渲染特性和控制脚本
- **路径**: `Assets/_Project/Scripts/Systems/TimeAccelerationRenderFeature.cs`
- **功能**: URP渲染特性和滤镜控制系统
- **集成**: 自动响应天堂制造状态变化

## ⚠️ 重要：URP配置步骤

### 第一步：配置URP渲染器
1. 打开 `Assets/Settings/Renderer2D.asset`
2. 在Inspector面板中找到 **Renderer Features** 部分
3. 点击 **Add Renderer Feature** 按钮
4. 选择 **Time Acceleration Render Feature**
5. 将 `TimeAccelerationFilter.mat` 拖入 **Material** 字段
6. 确保 **Is Enabled** 选项已勾选

### 第二步：添加控制脚本
1. 在场景中创建空GameObject（命名为"TimeAccelerationFilter"）
2. 添加 `TimeAccelerationFilterSystem` 组件
3. 在Inspector中设置相关参数

## 视觉效果

### 径向模糊 (Radial Blur)
- **效果**: 从屏幕中心向外的运动模糊
- **用途**: 模拟时间加速时的视觉冲击
- **参数**: `_RadialBlur` (0-0.1)

### 色彩偏移 (Chromatic Aberration)
- **效果**: RGB通道分离，产生彩虹色散
- **用途**: 增强时空扭曲的感觉
- **参数**: `_ChromaticAberration` (0-0.02)

### 径向扭曲 (Radial Distortion)
- **效果**: 从中心向外的空间扭曲
- **用途**: 模拟时空弯曲效果
- **参数**: `_Distortion` (0-0.1)

### 动态调制
- **亮度脉冲**: 随时间变化的亮度波动
- **饱和度变化**: 色彩饱和度的动态调整
- **色相偏移**: 轻微的色调变化

## 使用方法

### 自动集成
完成URP配置后，系统会自动响应天堂制造状态：
- **天堂制造启动** → 滤镜淡入激活
- **天堂制造停止** → 滤镜淡出关闭

### 手动控制
```csharp
// 启动滤镜
TimeAccelerationFilterSystem.Instance.StartTimeAccelerationFilter();

// 停止滤镜
TimeAccelerationFilterSystem.Instance.StopTimeAccelerationFilter();

// 设置强度（0-1）
TimeAccelerationFilterSystem.Instance.SetFilterIntensity(0.8f);

// 获取状态
bool isActive = TimeAccelerationFilterSystem.Instance.IsFilterActive;
float intensity = TimeAccelerationFilterSystem.Instance.CurrentIntensity;
```

### 测试功能
在编辑器中启用 **Enable Manual Testing** 后：
- **F1键**: 启动滤镜测试
- **F2键**: 停止滤镜测试
- **F3键**: 循环强度测试

## 配置参数

### Inspector设置

#### 滤镜设置
- **Time Acceleration Material**: 滤镜材质引用
- **Target Camera**: 目标相机（默认主相机）

#### 动画参数
- **Transition Duration**: 过渡时间（默认1秒）
- **Transition Curve**: 过渡曲线

#### 效果参数
- **Max Intensity**: 最大强度（0-1）
- **Max Radial Blur**: 最大径向模糊强度
- **Max Chromatic Aberration**: 最大色彩偏移强度
- **Max Distortion**: 最大扭曲强度
- **Max Brightness**: 最大亮度倍数
- **Max Saturation**: 最大饱和度倍数
- **Time Speed**: 时间动画速度

#### 调试选项
- **Show Debug Logs**: 显示调试日志
- **Enable Manual Testing**: 启用手动测试（编辑器中按F1/F2/F3）

## 完整集成步骤

## 注意事项

### 性能考虑
1. **移动设备**: 后处理效果会影响性能，建议在低端设备上降低效果强度
2. **渲染管线**: 仅支持URP，不兼容Built-in或HDRP
3. **多相机**: 每个需要效果的相机都需要配置

### 兼容性
1. **Unity版本**: 需要Unity 2021.3或更高版本
2. **渲染管线**: 必须使用Universal Render Pipeline
3. **平台**: 支持所有URP兼容平台

### 已知限制
1. **VR支持**: 在VR中可能需要调整扭曲参数避免晕动症
2. **多显示器**: 仅影响指定的目标相机
3. **UI元素**: 会影响整个相机渲染，包括UI

## 故障排除

### 常见问题及解决方案

#### 1. 滤镜完全无效果
**可能原因**:
- URP渲染特性未正确配置
- 材质未设置或Shader编译失败
- RenderFeature被禁用

**解决步骤**:
1. 检查 `Renderer2D.asset` 中是否添加了 `TimeAccelerationRenderFeature`
2. 确认材质字段已设置且Shader无错误
3. 验证RenderFeature的"Is Enabled"选项已勾选
4. 重新导入Shader文件

#### 2. 滤镜强度为0
**可能原因**:
- 材质参数被重置
- 系统未正确初始化

**解决步骤**:
1. 使用F1键手动启动滤镜测试
2. 检查控制台是否有错误日志
3. 确认TimeAccelerationFilterSystem脚本已添加到场景中

#### 3. 与天堂制造集成失效
**可能原因**:
- MadeInHeavenSystem事件未正确订阅
- 脚本执行顺序问题

**解决步骤**:
1. 确认MadeInHeavenSystem存在且正常工作
2. 检查OnMadeInHeavenStateChanged事件是否正确触发
3. 在Unity脚本执行顺序中调整TimeAccelerationFilterSystem

#### 4. 性能问题
**解决方案**:
- 降低maxIntensity值
- 减少Shader采样次数
- 在移动设备上禁用某些效果

### 调试工具
- **启用调试日志**: 勾选"Show Debug Logs"查看详细信息
- **手动测试**: 启用"Enable Manual Testing"使用F1-F3键测试
- **状态查询**: 使用GetStatusInfo()方法获取系统状态

### URP特定注意事项
- 确保使用URP 2021.3或更高版本
- 不要混用Built-in渲染管线的后处理方法
- RenderFeature必须添加到正确的渲染器资源中
