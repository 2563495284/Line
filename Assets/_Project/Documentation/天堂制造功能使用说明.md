# 天堂制造功能使用说明

## 功能概述

"天堂制造"是一个卡牌效果，激活后会让NPC系统和市场新闻系统每3秒自动执行一次，无需玩家手动点击"下一回合"按钮。**系统会在执行10次后自动停止**，提供平衡的游戏体验。

## 核心组件

### 1. 三个GameAction（重构版）

#### StartMadeInHeavenGA
- 启动天堂制造模式的游戏动作
- 执行时让NPCSystem和MarketEventSystem取消对NextRoundTurnGA的订阅
- 改为订阅MadeInHeavenExecuteGA

#### EndMadeInHeavenGA
- 结束天堂制造模式的游戏动作
- 让系统恢复对NextRoundTurnGA的订阅
- 取消对MadeInHeavenExecuteGA的订阅

#### MadeInHeavenExecuteGA
- 天堂制造执行动作，在天堂制造模式下替代NextRoundTurnGA
- 提供扩展接口供用户处理额外逻辑
- 包含OnExecute委托和ExecuteData数据传递

### 2. MadeInHeavenEffect.cs
- 卡牌效果类，返回StartMadeInHeavenGA
- 可在Inspector中调整自动执行间隔时间（默认3秒）

### 3. AutoSystemManager.cs
- 核心管理器，响应三个GA的执行
- 管理自动执行协程和状态
- 提供自定义执行逻辑接口

### 4. 系统动态订阅机制
- **NPCSystem**: 支持在NextRoundTurnGA和MadeInHeavenExecuteGA之间切换订阅
- **MarketEventSystem**: 同样支持动态订阅切换
- 通过解除/注册来避免NextRound的影响

### 5. PlayerView.cs 集成
- 按钮UI已集成天堂制造控制
- 支持两种操作模式：手动模式和天堂制造模式

## 使用方法

### 启动天堂制造
1. **通过卡牌**：使用"天堂制造"卡牌自动启动
2. **手动启动**：按住Shift键点击"下一回合"按钮
3. **代码调用**：`AutoSystemManager.Instance.StartMadeInHeaven()`

### 停止天堂制造
1. **右键点击**：在天堂制造模式下右键点击"下一回合"按钮停止
2. **自动停止**：执行10次后自动停止
3. **代码调用**：`AutoSystemManager.Instance.StopMadeInHeaven()`

## UI状态显示

### 正常模式
- 按钮显示："下一回合\n(Shift+点击启动天堂制造)"
- 按钮颜色：白色

### 天堂制造模式
- 按钮显示："下一回合\n🌟 天堂制造: X/10 (剩余Y次)\n(右键停止)"
- 按钮颜色：金色
- 实时显示执行进度和剩余次数
- 系统每3秒自动执行，10次后自动停止
- 玩家可以正常点击进行下一回合，不会中断天堂制造

## 技术实现

### 新架构流程
```
卡牌使用 → StartMadeInHeavenGA → AutoSystemManager响应
                                      ↓
                            启动协程定时器 → MadeInHeavenExecuteGA + NextRoundTurnGA
                                      ↓                    ↓
                   NPCSystem & MarketEventSystem        玩家系统（能量、摸牌、属性等）
                          响应执行                          正常工作
```

### 动态订阅机制
- **NPC和市场系统**：
  - 启动时：取消对NextRoundTurnGA的订阅，改为订阅MadeInHeavenExecuteGA
  - 结束时：恢复对NextRoundTurnGA的订阅，取消MadeInHeavenExecuteGA订阅
  - 实现NPC和市场新闻的自动化
- **玩家系统**：
  - 始终保持对NextRoundTurnGA的订阅
  - 确保能量、摸牌、属性变化等功能正常工作
  - 无论天堂制造是否激活，玩家功能都不受影响
- **双重触发**：天堂制造自动执行时同时触发MadeInHeavenExecuteGA和NextRoundTurnGA

### 扩展接口
- **MadeInHeavenExecuteGA**: 纯净的GameAction，通过ActionSystem监听来扩展功能
- **系统监听**: 任何系统都可以通过`ActionSystem.SubscribeReaction<MadeInHeavenExecuteGA>`来响应天堂制造执行

### 状态管理
- 使用事件系统通知UI状态变化
- 支持动态调整执行间隔
- 错误处理：发生异常时自动停止
- 内外部调用分离：避免循环调用问题

## 配置选项

### AutoSystemManager 设置
- `defaultAutoInterval`: 默认执行间隔（3秒）
- `maxExecuteCount`: 最大执行次数（10次），达到后自动停止
- `showDebugLogs`: 是否显示调试日志

### PlayerView 设置
- `enableMadeInHeavenControl`: 是否启用天堂制造控制
- 可通过Inspector禁用此功能

## 玩家功能保障

### 🎮 玩家系统完全不受影响
- **能量系统**：每回合正常恢复能量，耐心属性正常保存能量
- **卡牌系统**：正常丢牌摸牌，社交属性影响摸牌数量
- **属性系统**：社交和耐心属性正常每回合递减
- **股票系统**：股价正常刷新，玩家交易不受影响
- **游戏进度**：回合计数正常，胜负判定正常

### 📱 操作体验
- **天堂制造模式下**：玩家点击"下一回合"按钮正常工作，**不会中断天堂制造**
- **停止天堂制造**：右键点击"下一回合"按钮停止天堂制造
- **自动执行时**：每3秒同时触发NPC行动、市场新闻和玩家回合逻辑
- **完美兼容**：玩家可以在天堂制造运行的同时正常进行游戏

## 注意事项

1. **性能**：天堂制造会频繁触发系统更新，注意性能影响
2. **游戏平衡**：此功能会显著改变游戏节奏，建议谨慎使用
3. **错误处理**：系统异常时会自动停止，确保游戏稳定性
4. **兼容性**：与现有冷却系统完全兼容

## 扩展开发

### 添加自定义执行逻辑
```csharp
// 正确方式：通过监听MadeInHeavenExecuteGA来实现额外逻辑
public class MyCustomSystem : MonoBehaviour
{
    private void OnEnable()
    {
        // 监听天堂制造执行事件
        ActionSystem.SubscribeReaction<MadeInHeavenExecuteGA>(OnMadeInHeavenExecute, ReactionTiming.POST);
    }
    
    private void OnDisable()
    {
        ActionSystem.UnsubscribeReaction<MadeInHeavenExecuteGA>(OnMadeInHeavenExecute, ReactionTiming.POST);
    }
    
    private void OnMadeInHeavenExecute(MadeInHeavenExecuteGA executeGA)
    {
        // Debug.Log("天堂制造执行时的自定义逻辑！");
        // 这里可以处理你的额外逻辑
        // 例如：特殊的UI更新、数据统计、音效播放等
    }
}
```

### 添加新的自动系统
1. 创建系统类同时订阅 `NextRoundTurnGA` 和 `MadeInHeavenExecuteGA` 事件
2. 在 `OnEnable/OnDisable` 中注册/取消订阅
3. 响应 `StartMadeInHeavenGA` 和 `EndMadeInHeavenGA` 来切换订阅
4. 系统将自动适配天堂制造模式

```csharp
public class MyCustomSystem : Singleton<MyCustomSystem>
{
    private bool isSubscribedToNextRound = false;
    private bool isSubscribedToMadeInHeaven = false;

    private void OnEnable()
    {
        SubscribeToNextRound();
        ActionSystem.SubscribeReaction<StartMadeInHeavenGA>(OnStartMadeInHeaven, ReactionTiming.POST);
        ActionSystem.SubscribeReaction<EndMadeInHeavenGA>(OnEndMadeInHeaven, ReactionTiming.POST);
    }

    private void OnStartMadeInHeaven(StartMadeInHeavenGA action)
    {
        UnsubscribeFromNextRound();
        SubscribeToMadeInHeaven();
    }

    private void OnEndMadeInHeaven(EndMadeInHeavenGA action)
    {
        UnsubscribeFromMadeInHeaven();
        SubscribeToNextRound();
    }

    // ... 实现订阅管理方法
}
```

### 系统配置和状态查询
```csharp
// 设置为5秒间隔
AutoSystemManager.Instance.SetAutoInterval(5.0f);

// 设置为15次后停止（默认10次）
AutoSystemManager.Instance.SetMaxExecuteCount(15);

// 获取当前进度信息
var manager = AutoSystemManager.Instance;
int current = manager.CurrentExecuteCount;        // 当前已执行次数
int max = manager.MaxExecuteCount;              // 最大执行次数
int remaining = manager.RemainingExecuteCount;   // 剩余执行次数
bool isActive = manager.IsMadeInHeavenActive;   // 是否激活

// 获取状态信息字符串
string status = manager.GetStatusInfo();
// 输出示例："天堂制造: 激活中 (间隔: 3s, 进度: 3/10)"

// 手动停止天堂制造
AutoSystemManager.Instance.StopMadeInHeaven();

// 手动启动天堂制造
AutoSystemManager.Instance.StartMadeInHeaven();
```
