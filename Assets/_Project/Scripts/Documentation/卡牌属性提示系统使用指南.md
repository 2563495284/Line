# 卡牌属性提示系统使用指南

## 概述

卡牌属性提示系统为游戏提供了类似《杀戮尖塔》的卡牌悬停效果，当玩家将鼠标悬停在卡牌上时，会在卡牌右侧显示相关属性的详细信息。同时，系统支持基于玩家属性（如魅力、勇气）的动态数值显示和高亮效果。

## 主要功能

### 1. 动态数值显示
- 卡牌描述中的数值会根据玩家当前属性实时计算
- 支持魅力、勇气等属性对卡牌效果的影响
- 自动高亮显示受属性影响的数值

### 2. 属性提示框
- 悬停时在卡牌右侧显示相关属性信息
- 高亮显示卡牌引用的属性
- 从上到下排列多个属性描述

### 3. 富文本支持
- 属性名称和数值的颜色高亮
- 支持TextMeshPro的富文本标记
- 美观的视觉效果

## 核心组件

### 1. CardDescriptionSystem（卡牌描述系统）
负责处理卡牌描述中的动态数值和高亮显示。

**主要方法：**
```csharp
// 处理卡牌描述，返回包含动态数值的结果
CardDescriptionResult ProcessCardDescription(string originalDescription, Card card)

// 获取卡牌引用的属性类型
List<EPlayerAttributeType> GetReferencedAttributes(string description)
```

### 2. AttributeTooltipDisplay（属性提示框显示）
管理属性提示框的显示和隐藏。

**主要方法：**
```csharp
// 显示属性提示框
void Show(List<EPlayerAttributeType> attributeTypes, 
          List<EPlayerAttributeType> highlightedAttributes, 
          Vector3 worldPosition)

// 隐藏属性提示框
void Hide()
```

### 3. AttributeTooltipItem（属性提示框项目）
单个属性信息的显示组件。

**主要方法：**
```csharp
// 设置属性信息
void Setup(PlayerAttributeData attributeData, bool isHighlighted = false)

// 设置高亮状态
void SetHighlight(bool highlighted)
```

## 使用方法

### 1. 卡牌描述中使用属性标记

在CardData的Description字段中使用以下两种标记方式：

#### 方式一：基础数值+属性影响（推荐）
```
1{魅力}% - 基础1%，受魅力属性影响
5{勇气} - 基础5点，受勇气属性影响
2{智慧}% - 基础2%，受智慧属性影响
```

#### 方式二：纯属性标记（用于属性引用）
```
{魅力} - 引用魅力属性，只高亮属性名称
{勇气} - 引用勇气属性，只高亮属性名称
{智慧} - 引用智慧属性，只高亮属性名称
{社交} - 引用社交属性，只高亮属性名称
{耐心} - 引用耐心属性，只高亮属性名称
{冷静} - 引用冷静属性，只高亮属性名称
{狂热} - 引用狂热属性，只高亮属性名称
```

**适用场景：**
- 描述中提到属性但不需要数值计算
- 例如："获得2层{耐心}"、"消耗{勇气}点体力"

**示例卡牌描述：**
```
"利用你的魅力影响市场，提升股价 1{魅力}%"
```

**计算逻辑：**
- 如果玩家魅力为3，影响系数为30%（3 × 10%）
- 最终效果：1% × (1 + 30%) = 1.3%
- 显示为："利用你的魅力影响市场，提升股价 <color=#FFD700><b>1.3</b></color>%"

### 2. 设置UI组件

在CardViewHoverSystem中设置AttributeTooltipDisplay引用：

```csharp
[SerializeField] private AttributeTooltipDisplay attributeTooltipDisplay;
```

### 3. 创建属性提示框预制体

#### 世界空间模式（推荐，适配3D卡牌）
创建包含以下组件的预制体：
- AttributeTooltipDisplay（主控制器）
- CanvasGroup（用于淡入淡出动画）
- 容器Transform（用于放置提示项目）
- AttributeTooltipItem预制体（单个属性显示项目）

#### UI空间模式（适配2D UI卡牌）
如果卡牌在UI Canvas中，可以使用传统的UI空间模式。

### 4. 配置属性提示项目预制体

#### 世界空间模式的AttributeTooltipItem预制体需要包含：
- TextMeshPro（属性名称，世界空间）
- TextMeshPro（属性描述，世界空间）
- SpriteRenderer（背景）
- SpriteRenderer（图标，可选）

#### UI空间模式的AttributeTooltipItem预制体需要包含：
- TextMeshProUGUI（属性名称）
- TextMeshProUGUI（属性描述）
- Image（背景）
- Image（图标，可选）

## 属性影响计算

系统支持两种计算模式：

### 新模式：基础值 × (1 + 属性影响系数)

**影响系数计算：**
- 魅力：每点魅力增加10%效果（3点魅力 = 30%加成）
- 勇气：每点勇气增加10%效果（2点勇气 = 20%加成）
- 智慧：每点智慧增加10%效果
- 社交：每点社交增加10%效果
- 耐心：每点耐心增加10%效果
- 冷静：每点冷静增加10%效果
- 狂热：每点狂热增加10%效果

**计算示例：**
```
描述："提升股价 1{魅力}%"
玩家魅力：3点
影响系数：3 × 10% = 30%
最终效果：1% × (1 + 30%) = 1.3%
```

### 旧模式：直接属性值替换（向后兼容）

**直接值计算：**
- 魅力：`attributeValue * 10f`（每点魅力增加10%效果）
- 勇气：`attributeValue`（每点勇气增加1点交易数量）
- 智慧：`attributeValue`
- 社交：`attributeValue`
- 耐心：`attributeValue`
- 冷静：`attributeValue * 10f`
- 狂热：`attributeValue * 10f`

## 示例用法

### 创建一张魅力卡牌（新模式）

1. **创建CardData资源：**
   - Title: "魅力攻势"
   - Description: "利用你的魅力影响市场，提升股价 1{魅力}%"
   - 其他效果设置...

2. **效果：**
   - 如果玩家魅力为3，计算过程：1% × (1 + 30%) = 1.3%
   - 描述会显示为："利用你的魅力影响市场，提升股价 <color=#FFD700><b>1.3</b></color>%"
   - 悬停时右侧会显示魅力属性的详细信息
   - 只有受影响的数值会被高亮，"魅力"文字不会变色

### 创建一张复合属性卡牌（新模式）

1. **创建CardData资源：**
   - Title: "全力出击"
   - Description: "发挥你的能力，影响力+2{魅力}%，交易量+5{勇气}"

2. **效果：**
   - 魅力3点：2% × (1 + 30%) = 2.6%
   - 勇气2点：5 × (1 + 20%) = 6
   - 显示："发挥你的能力，影响力+<color=#FFD700><b>2.6</b></color>%，交易量+<color=#FFD700><b>6</b></color>"
   - 悬停时显示两个属性的信息框

### 纯属性引用示例

1. **创建CardData资源：**
   - Title: "耐心修炼"
   - Description: "获得2层{耐心}，提升防御能力"

2. **效果：**
   - 描述会显示为："获得2层{<color=#87CEEB>耐心</color>}，提升防御能力"
   - 悬停时右侧会显示耐心属性的详细信息
   - 只有属性名称被高亮，数值"2层"保持不变

### 混合使用示例

1. **创建CardData资源：**
   - Title: "综合策略"
   - Description: "消耗{勇气}点体力，提升股价 1{魅力}%"

2. **效果：**
   - 勇气3点，魅力3点时显示：
   - "消耗{<color=#87CEEB>勇气</color>}点体力，提升股价 <color=#FFD700><b>1.3</b></color>%"
   - 悬停时显示勇气和魅力两个属性的信息框

## 性能优化

1. **缓存机制：**
   - 卡牌描述结果会被缓存，避免重复计算
   - 只在属性值变化时更新描述

2. **对象池：**
   - AttributeTooltipItem使用对象池管理
   - 避免频繁创建销毁UI对象

3. **更新策略：**
   - 只在悬停时更新描述
   - 批量更新多个卡牌

## 世界空间配置指南

### 1. 创建世界空间AttributeTooltipItem预制体

1. **创建基础GameObject**：
   ```
   AttributeTooltipItem (GameObject)
   ├── Background (SpriteRenderer) - 背景
   ├── Icon (SpriteRenderer) - 图标（可选）
   ├── AttributeName (TextMeshPro) - 属性名称
   └── AttributeDescription (TextMeshPro) - 属性描述
   ```

2. **配置TextMeshPro组件**：
   - 设置合适的字体大小（建议0.1-0.2）
   - 启用自动调整大小
   - 设置合适的颜色和材质

3. **配置SpriteRenderer**：
   - 设置背景精灵（可以是简单的矩形）
   - 调整颜色和透明度
   - 设置合适的排序层级

### 2. 布局参数调整

对于世界空间显示，需要调整以下参数：

```csharp
// AttributeTooltipDisplay 世界空间参数
[SerializeField] private Vector3 tooltipOffset = new Vector3(2f, 0f, 0f); // 右侧偏移2个单位
[SerializeField] private float itemSpacing = 0.5f; // 项目间距0.5个单位

// CardViewHoverSystem 世界空间参数
[SerializeField] private Vector3 tooltipOffset = new Vector3(3f, 0f, 0f); // 相对卡牌偏移
```

### 3. 摄像机朝向设置

世界空间的提示框会自动朝向主摄像机，确保文本始终可读：

```csharp
// 在AttributeTooltipItem中自动处理
transform.LookAt(Camera.main.transform);
transform.Rotate(0, 180, 0); // 翻转以正确显示
```

### 4. 性能优化建议

1. **合理设置文本分辨率**：TextMeshPro的世界空间文本建议使用较低的分辨率
2. **使用对象池**：频繁显示隐藏时使用对象池管理
3. **LOD系统**：距离较远时可以隐藏或简化显示

## 常见问题

### Q: 属性提示框不显示
A: 检查AttributeTooltipDisplay引用是否正确设置，确保预制体配置完整

### Q: 高亮效果不生效
A: 确保TextMeshPro组件启用了富文本支持

### Q: 数值计算不正确
A: 检查CalculateEffectValue方法中的计算逻辑，确保属性值获取正确

### Q: 性能问题
A: 减少不必要的描述更新，使用对象池管理UI组件
